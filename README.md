A program that writes two lines to `/output/entry.txt` (327 characters, inside the 400-character cap). Line 1 explains a queue to a 10-year-old through one analogy — a caterpillar made of people, standing in single file and wiggling forward one step at a time. Line 2 is honest about that analogy: it maps the single-file line and the slow forward wiggle, but leaves out that a real caterpillar never gets bored, never cuts in line, and never leaves to come back later.

## Run it

```sh
python3 main.py
```
